# Contributing

Thanks for your interest in contributing to Vinato.

## Getting Started

1. Fork the repository and create a feature branch from `main`.
2. Follow the setup instructions in the README.
3. Make your changes, keeping diffs focused and minimal.
4. Open a pull request with a clear description of what changed and why.

## Guidelines

- Keep changes scoped. One PR per feature or fix.
- Do not commit secrets, credentials, or personal data.
- Match the existing code style (vanilla JS, no frameworks in the storefront).
- Test your changes in both Arabic (RTL) and English (LTR) layouts.
- Check that the admin dashboard still works after any storefront changes.

## Reporting Issues

Open a GitHub issue with:
- A clear description of the problem
- Steps to reproduce
- Expected vs actual behaviour
- Browser/OS if it's a visual or layout issue

## Security

For security vulnerabilities, please follow the process described in [SECURITY.md](SECURITY.md) rather than opening a public issue.
